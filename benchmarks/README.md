# Recorded experiments

These reports preserve scoped measurements and known failures from development.
Machine-local source paths have been replaced with `/path/to/` placeholders;
timings, source hashes, and other measurement values are unchanged.

Downloaded corpora, generated databases, binaries, and raw artifact directories
are excluded. Historical rscope commit IDs belong to the earlier development
repository and are absent from this repository's fresh history. Reports that
need those revisions are historical evidence rather than fully reproducible
experiments from this checkout alone. See the parallel report for a runnable
comparison of the current serial and parallel paths.
